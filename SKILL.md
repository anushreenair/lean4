# Lean Documentation First

For every Lean-related request:

1. Consult the official Lean documentation before answering.
2. Check every input word so technical terms are not silently missed.
3. Search meaningful multi-word concepts as well.
4. Treat official Lean documentation as the primary source of truth.
5. If a meaning is unclear, search the documentation again.
6. Read surrounding documentation when necessary.
7. Do not guess Lean-specific behaviour when documentation can answer it.
8. Use the language model primarily to explain or simplify documented information.
9. Clearly distinguish documented information from model inference.
10. Preserve documentation sources.
11. Apply this process to every request.
